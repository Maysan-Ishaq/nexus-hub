# Nexus Hub™️

##### *Thought, interaction, control, life.*

![Banner](./assets/NexusBanner.svg)

A connected office assistant, designed to optimize, simplify, and make every office task fun, in order to breathe new life into our machines.

## Why THIS project ?

Easy. I needed a "real-life" personal assistant (and a friend 😊) who was always ready to help me when I got stuck on some code, whether I was on the go and didn't have access to my computer, or even just to be my "developer's rubber duck."

## Features

### Hardware

 - Voice communication (microphone and speaker)
 - Wi-Fi connectivity

### Software

 - Windows desktop app
 - Facial recognition
 - Spitch-to-text and text-to-spitch

### Needed stuff

 - Raspberry Pi 4 MOD B 8GB
 - Raspberry Pi Camera 3
 - Raspberry Pi AC/DC Adapter 5.1V 15W
 - Adafruit Mini USB Microphone
 - PUI Audio 8Ohm 3W86DB Speaker
 - Adafruit Mono Output Class D Audio Amplifier (for the PCB)
 - 2.54MM Female Header 2X20 pins (for the PCB too)
